# HomeWork2

Этот проект создан для укрепления знаний по объектно-ориентированному программированию (ООП) на Python. В рамках проекта реализованы базовые классы для работы с продуктами и категориями товаров, а также функции для чтения данных из JSON-файла и создания объектов на основе этих данных.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/daniel-ocean97/HomeWork2.git
2. Перейдите в директорию проекта:

       cd HomeWork2
3. Убедитесь, что у вас установлен Python 3.x.

4. Запустите тесты для проверки функционала:

        python -m pytest Tests/
5. Для использования функционала проекта, вы можете импортировать классы и функции из модулей product.py и utils.py в свои скрипты.
   
### Описание модулей

1. **`product.py`**:
   - Содержит два основных класса:
     - `Product`: Описывает продукт с атрибутами: `name`, `description`, `price`, `quantity`.
     - `Category`: Описывает категорию товаров с атрибутами: `name`, `description`, `products`. Также содержит статические переменные для подсчёта количества категорий и продуктов.

2. **`utils.py`**:
   - Содержит функции для работы с JSON-файлами:
     - `read_from_json(path)`: Читает данные из JSON-файла и возвращает их в виде Python-объекта.
     - `create_objects_from_json(data)`: Создаёт объекты классов `Product` и `Category` на основе данных, полученных из JSON-файла.

3. **`Tests/`**:
   - В этой папке находятся модули для тестирования функционала проекта. Тесты позволяют проверить корректность работы классов и функций.

4. **`data/products.json`**:
   - JSON-файл, содержащий данные о продуктах и категориях, которые используются для создания объектов в проекте.
